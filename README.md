# 🎮 Beat Ninja

A simple Fruit Ninja–style arcade slicing game made with HTML, CSS, and JavaScript.

## 👤 Creator
Made by **null**

---

## 🕹️ How to Play

- Choose your device:
  - 💻 Computer → use mouse to slice
  - 📱 Mobile → use finger to swipe

- Slice the colored cubes to earn points
- Avoid the black bombs ⚫ (they reset your score)
- Don’t miss too many cubes or you lose lives ❤️

---

## 🎯 Game Modes

- Easy → slower spawns, relaxed gameplay
- Medium → balanced difficulty
- Hard → fast-paced challenge

---

## ⚙️ Features

- Smooth arc-based movement (Fruit Ninja style)
- Mobile + PC support
- Bomb system with score reset
- Lives system (❤️❤️❤️)
- Game over cutscene with animated score
- Device selection screen before gameplay
- Clean home menu

---

## 📁 Files

- `index.html` → main game file (everything included)

## 🚀 How to Run

1. Download the project
2. Open `index.html` in any modern browser
3. Play instantly — no installs needed
